# brain-time
A mental health tracking application, where you can keep track of how you're feeling, find suggested activities based on your current mood and nurture a virtual pet that represents your mental health. 

## Afterword 
This was a shared project for a midsemester uni hackathon in 2021. None of us knew how to write JS, so getting some web code working was really great practice even if it didn't fulfil the vision!
